# Results

This file summarizes the actual evaluation output collected from the trained checkpoints in this repository. I kept it short and readable on purpose so that a reviewer can understand the outcome quickly.

## Dataset Snapshot

- Number of samples: 5000
- Vocabulary size: 25
- Maximum padded sequence length: 30
- Observed maximum input length: 13
- Observed maximum target length: 26
- Target task: fourth-order Taylor expansion around `x = 0`

## Models Evaluated

### LSTM Seq2Seq

- Training script: `src/training/train_lstm.py`
- Embedding size: 128
- Hidden size: 256
- Layers: 2

### Transformer Seq2Seq

- Training script: `src/training/train_transformer.py`
- Embedding size: 128
- Attention heads: 8
- Layers: 3

The models were evaluated on the first 100 processed examples using:

### Transformer

## Example Outputs

### Example 1

- Predicted: `x * ( 6 - x ** 2 ) / 3`
- Target: `x * ( 6 - x ** 2 ) / 3`

### Example 2

- Predicted: `x * ( - 3 * x ** 3 + 4 * x ** 2 - 6 * x + 24 ) / 12`
- Target: `x * ( - 3 * x ** 3 + 4 * x ** 2 - 6 * x + 24 ) / 12`

### Example 3

- Predicted: `x ** 4 / 24 + x ** 3 / 6 + x ** 2 / 2 + x + 1`
- Target: `x ** 4 / 24 + x ** 3 / 6 + x ** 2 / 2 + x + 1`

## Interpretation

On the 100-example evaluation slice that was tested, both models produced perfect scores across all three metrics. That means the predictions matched the target sequences exactly and were also mathematically equivalent under SymPy simplification.

Even though both models scored perfectly on this slice, the Transformer is still the stronger final model for presentation because it is more scalable and better suited to harder symbolic sequence tasks.

## Practical Note

The reported numbers above came from real evaluation runs using:

```bash
python src/evaluation/evaluate_model.py --model lstm --num-examples 100
python src/evaluation/evaluate_model.py --model transformer --num-examples 100
```

Checkpoint files are intentionally not committed to the repository, but they can be regenerated by rerunning the training scripts.
