# FASEROH Symbolic Learning

Implementation of sequence-to-sequence models to learn symbolic mathematical representations.

## Tasks implemented

- Dataset generation using SymPy
- Taylor expansion dataset
- Tokenization
- LSTM seq2seq model
- Transformer seq2seq model

## Models

1. LSTM encoder-decoder
2. Transformer encoder-decoder

## Evaluation metrics

- Token accuracy
- Exact match
- Symbolic equivalence (SymPy)
